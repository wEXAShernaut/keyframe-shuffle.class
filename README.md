# Jankenpo no navegador via Cordova

Jogo de pedra, papel e tesoura rodando no navegador empacotado com Cordova

## Demonstração

Há uma gravação mostrando o jogo.

## Instalação

Instale a ferramenta de forma global:

```
npm install -g cordova
```

## Execução

Estando na raiz do projeto:

```
> cordova run browser # (numa janela de terminal, dentro da pasta raiz)
```

## Se não funcionar de primeira

Depois de instalar a ferramenta pelo gerenciador de pacotes, acrescente a plataforma de navegador e tente de novo.

```
> cordova plaform add browser # (numa janela de terminal, dentro da pasta raiz).
```
